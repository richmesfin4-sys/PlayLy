Sync Features Verified:
  • Simultaneous Play/Pause: Press Play once to start both videos in sync.
  • Lockstep Seeking: Scrubbing the timeline keeps both videos aligned to the exact frame.
  • Side-by-Side View (◫): Click the ◫ button in the sign toolbar to split the stage 50/50 so tutorial code and sign interpreter are both 100% visible.
  • Movable Floating Window: Switch to PiP and drag the EthSL window anywhere across the page.
